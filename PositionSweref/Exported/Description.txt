Title: GPS Information in SWEREF 99 TM

News:
- A new version of the app will come soon for modern devices with Glance support
- Data field is coming soon

English:
This app shows the actual GPS position in the swedish coordinate System SWEREF 99 TM. This makes it easier to find yourself on maps based on this system like Calazo maps or Fjällkartan maps.

The app needs some startup time to get a proper GPS signal. "????" was replaced by "Searching".

App was programmed in the style of simplicity:
* no logging
* simple Design
* no persistent memory needed

Version 1.20:
- GPS activated on start of widget
- device specific layouts
- new string labels
